## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/MessiasSavio/portifolio.git
```

2. Navegue até a pasta:
```bash
cd portifolio/portifolio
```

3. Abra o arquivo `index.html` em um navegador ou use um servidor local:
```bash
# Usando Python
python -m http.server 8000

# Usando Node.js
npx serve .
```
