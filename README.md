## 📋 Padrão de Nomenclatura

Os certificados seguem o padrão:
```
[Ano]-[Mês]-[Dia]_[Instituição]_[Nome_do_Curso]_[Especialização].pdf
```

Exemplo:
```
2024-03-15_Alura_Java_Spring_Boot_API_Rest.pdf
2024-05-20_DIO_Machine_Learning_Python.pdf
```
